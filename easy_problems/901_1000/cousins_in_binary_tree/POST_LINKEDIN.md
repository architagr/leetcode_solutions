**Cousins in Binary Tree** (Easy)
🔗 https://leetcode.com/problems/cousins-in-binary-tree/

Cousins boils down to two facts you need for each node: depth, and parent. Depth is
free while walking down. Parent is the fun part — no parent pointers on a plain binary
tree, but since every value is unique, a node's own value can stand in for its parent's
identity, so a helper can hand back the *parent's value* instead of a pointer.
