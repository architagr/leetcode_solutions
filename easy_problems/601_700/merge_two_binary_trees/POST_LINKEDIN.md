**Merge Two Binary Trees** (Easy)
🔗 https://leetcode.com/problems/merge-two-binary-trees/

Overlay two trees, add up whatever overlaps, and keep whatever's left when only one
side has a node there. The bit I actually liked: you never build new nodes for the
non-overlapping parts, you just hand back whichever tree's subtree is real and let it
get reused as-is.
