**Search in a Binary Search Tree** (Easy)
🔗 https://leetcode.com/problems/search-in-a-binary-search-tree/

One comparison per node tells you whether the target can only be in the left subtree or
only in the right one, so there's nothing to backtrack over and no reason to check both
sides. It's the whole reason a BST beats a plain binary tree here: the recursion is a
straight walk from root to the answer instead of a full search.
