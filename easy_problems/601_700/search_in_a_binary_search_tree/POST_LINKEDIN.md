**Search in a Binary Search Tree** (Easy)
🔗 https://leetcode.com/problems/search-in-a-binary-search-tree/

The BST property does the work for you: one comparison at each node tells you whether
the target can *only* be in the left subtree or *only* in the right subtree — no
backtracking, no checking both sides. It's a straight root-to-node walk, not a full
tree search.
