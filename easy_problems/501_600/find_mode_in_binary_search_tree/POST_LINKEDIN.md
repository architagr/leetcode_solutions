**Find Mode in Binary Search Tree** (Easy)
🔗 https://leetcode.com/problems/find-mode-in-binary-search-tree/

The "BST" in the title is a bit of a red herring: the simplest fix is to ignore the
ordering entirely, tally every value's frequency in a hashmap, then read off whichever
value(s) hit the max count.
