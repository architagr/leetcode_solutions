**Find Mode in Binary Search Tree** (Easy)
🔗 https://leetcode.com/problems/find-mode-in-binary-search-tree/

The "BST" in the title looks like it should matter more than it does. The simplest fix
skips the ordering entirely: tally every value's frequency in a hashmap, then read off
whichever value (or values) hit the max count.
