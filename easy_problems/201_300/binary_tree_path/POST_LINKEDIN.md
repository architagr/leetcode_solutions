**Binary Tree Paths** (Easy)
🔗 https://leetcode.com/problems/binary-tree-paths/

A nice small DFS problem: walk root to leaf, build up the path string as you descend,
and lock it in the moment you hit a leaf. The one part that needed real thought is the
root, it doesn't get an arrow before its value the way every node below it does, so it
ends up needing its own bit of logic.
