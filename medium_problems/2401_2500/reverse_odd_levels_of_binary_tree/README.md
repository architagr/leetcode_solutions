# Reverse Odd Levels of Binary Tree

**Difficulty:** Medium  
**LeetCode:** [#2415](https://leetcode.com/problems/reverse-odd-levels-of-binary-tree/)

## Problem Statement

Given a perfect binary tree, reverse the node values at each odd level of the tree.

A perfect binary tree is a binary tree where all parent nodes have two children and all leaves are at the same level.

## Examples

**Example 1:**
```
Input: root = [1,2,3]
Output: [1,3,2]
```

**Example 2:**
```
Input: root = [1,2,3,4,5,6,7]
Output: [1,7,6,5,4,3,2]
```

## Constraints

- The number of nodes in the tree is in the range [1, 2^15 - 1].
- 1 <= Node.val <= 10^6
- root is a perfect binary tree.
