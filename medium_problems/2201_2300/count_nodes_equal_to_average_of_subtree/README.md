# Count Nodes Equal to Average of Subtree

**Difficulty:** Medium  
**LeetCode:** [#2265](https://leetcode.com/problems/count-nodes-equal-to-average-of-subtree/)

## Problem Statement

Given the root of a binary tree, return the number of nodes where the value of the node is equal to the average of the values in its subtree.

Note: The average of n elements is the sum of the n elements divided by n and rounded down to the nearest integer.

## Examples

**Example 1:**

![Example tree](images/example.jpg)

```
Input: root = [4,8,5,0,1,null,6]
Output: 5
```

**Example 2:**
```
Input: root = [1]
Output: 1
```

## Constraints

- The number of nodes in the tree is in the range [1, 1000].
- 0 <= Node.val <= 1000
