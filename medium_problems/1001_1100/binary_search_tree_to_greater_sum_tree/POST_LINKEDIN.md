## Binary Search Tree to Greater Sum Tree

**LeetCode:** [#1038 - Binary Search Tree to Greater Sum Tree](https://leetcode.com/problems/binary-search-tree-to-greater-sum-tree/)

Transform every node in a BST by adding the sum of all greater nodes. The trick: reverse in-order traversal (right-to-left) gives us nodes in descending order, so we can accumulate a running sum as we go.
