## Count Complete Tree Nodes

**LeetCode:** [#222 - Count Complete Tree Nodes](https://leetcode.com/problems/count-complete-tree-nodes/)

A complete binary tree is "almost" full—every level is completely filled except possibly the last, which is filled from left to right. The naive O(n) solution counts every node. The insight: use the tree's structure to recognize when an entire subtree is a perfect binary tree and skip traversing it.
