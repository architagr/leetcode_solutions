# leetcode_solutions

## It worked in dev

[`series/it-worked-in-dev/`](series/it-worked-in-dev/) is the long-form
companion to the daily challenge. Each episode takes a problem a working
developer has hit, benchmarks the version you would genuinely write first, and
derives the data structure from the symptom - with the code, the tests and the
benchmark committed so you can run them and get your own numbers.

It lives here rather than in its own repo because every episode backlinks the
days it is built on, so one clone gets you both.
